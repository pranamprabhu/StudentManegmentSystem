# Student Management System

A simple console-based Student Management System built in Java. This project demonstrates core programming concepts including array manipulation, loops, methods, error handling, and basic CRUD (Create, Read, Update, Delete) operations.

## Features

- **Add Student**: Add new students with a unique ID, Name, Age, and Grade.
- **Search Student**: Quickly look up a student's details using their ID.
- **Update Student**: Modify an existing student's name, age, or grade.
- **Display Students**: View all student records in a cleanly formatted table.
- **Input Validation**: Gracefully handles invalid inputs (like entering letters for IDs or Ages) to prevent the program from crashing.

## Technologies Used

- **Java** (Standard Edition)
- Uses built-in `Scanner` for console input.

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/pranamprabhu/StudentManegmentSystem.git
   ```
2. Navigate to the project directory:
   ```bash
   cd StudentManegmentSystem
   ```
3. Compile the Java file:
   ```bash
   javac StudentManagementSystem.java
   ```
4. Run the application:
   ```bash
   java StudentManagementSystem
   ```

## Usage Example

When you run the application, you'll be greeted with a menu:

```text
Welcome to the Student Management System

--- Menu ---
1. Add Student
2. Search Student
3. Update Student
4. Display All Students
5. Exit
Choose an option: 
```

Simply type the number corresponding to the action you want to perform and follow the on-screen prompts!
